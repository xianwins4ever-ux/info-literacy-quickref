## 一、中文文献三巨头：字段级对比

| 能力 | 知网 `cnki.mjs` | 万方 `wf.mjs` | 维普 `vp.mjs` |
|---|---|---|---|
| 按篇名/主题/关键词/作者/来源/摘要检索 | ✅ | ✅ | ✅（检索式） |
| 时间范围 | ✅ `--from --to` | ✅ `发表时间:(a-b)` | ✅ 检索式内 |
| 结果条数 | ✅ | ✅ | ✅ |
| **分库计数**（期刊/学位/会议/报纸…） | ✅（支持「万」单位） | ✅（左侧分面） | ⚠️ 仅总数 |
| **分面统计**（作者/机构/学科/年度…） | ✅ `--facet` | ⚠️ 作者分面无数据 | ❌ |
| 结果列表结构化（题名/作者/刊名/年卷期/被引/下载） | ✅ | ✅ | ✅ |
| **进详情页** | ✅ `--detail` | ✅ `--detail` | ✅ `--detail` |
| 题名 / 作者 | ✅ | ✅ | ✅ |
| **作者单位 / 机构** | ✅ | ✅ | ✅ |
| **DOI** | ✅ | ✅ | ⚠️ 部分有 |
| **ISSN** | ⚠️ 详情页无 | ✅ | ⚠️ 部分有 |
| 关键词 | ✅ | ✅ | ✅ |
| 分类号 | ✅ | ✅ | ✅ |
| **基金/资助** | ✅ | ✅ | ✅ |
| **年/卷/期/页码** | ✅ | ✅ | ✅ |
| 摘要 | ✅ | ✅ | ✅ |
| **GB/T 7714 引用** | ✅ | ✅ | ✅ |
| **MLA 引用** | ✅ | ✅ | ✅ |
| **APA 引用** | ✅ | ✅ | ✅ |
| 报纸类（[N] 格式） | ✅ | — | — |

**用法速记**：
```powershell
node cnki.mjs --ti "篇名" --top 1 --detail      # 知网：检索+详情+引用
node wf.mjs '题名:("篇名")' --detail             # 万方：检索+详情+引用
node vp.mjs 'K=关键词' --top 1 --detail          # 维普：检索+详情+引用
```

## 七、本轮修掉的 6 个真 bug

这些不是"没实现"，是**实现了但结果错**——比没实现更危险。

| # | bug | 后果 | 修法 |
|---|---|---|---|
| 1 | 知网库计数用**中文万单位**（`44.21万`） | 正则只抓 `44`，**所有超 1 万的计数全错** | 正则支持小数+万/亿并换算 |
| 2 | 知网点库标签切库**不生效** | 点「学术期刊」后第 1 条仍是报纸 | 改为**客户端按类型过滤** |
| 3 | 知网详情页裸 `h1` 抓到登录弹窗 | 题名变成「自动登录」 | 改用 `.wx-tit h1` |
| 4 | 知网作者带上标数字 | `李先平1韦朝东2` | 清理数字后拆分 |
| 5 | 万方 `--top` 用 innerText 正则 | **完全抓不到条目** | 改结构化 DOM（`.normal-list`） |
| 6 | 维普详情页标签与值**分行** | 作者/机构/基金全空 | pick 支持「标签行+下一行」 |

另修：万方结果页**渲染时机**（加轮询最多 25s）、万方详情 `DOI:` 半角冒号、国图 `--filter` 未作用于详情。
