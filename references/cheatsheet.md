## 二、`webq.mjs` —— 万能兜底（**不知道用哪个就用这个**）

```powershell
node webq.mjs "<URL>" --grep "关键词" --ctx 3      # 抓页面找关键词
node webq.mjs "<URL>" --links --filter "curriculum" # 列链接
node webq.mjs "<URL>" --json                        # JSON 接口
node webq.mjs "<URL>" --post "a=1&b=2"              # POST
node webq.mjs "<URL>" --raw                         # 原始 HTML
```

三个内置能力：**GBK/UTF-8 编码嗅探**、**正确的去标签顺序**、**`done()` 退出**（避免 libuv 断言崩溃）。

**判断标准**：返回字节数 **< 3KB** = SPA 壳，抓不到数据 → 改用专用脚本。

## 三、五个必须记住的坑

### 坑 1：知网引号必须英文半角

| 输入 | 学术期刊数 |
|---|---|
| 半角 `("AI" + "人工智能")` | **2,365** ✅ |
| 全角 `（“AI” + “人工智能”）` | 1,870 ❌ |

### 坑 2：知网「或」必须写在括号里，不要拆成独立行

行间只有 AND/OR 下拉、**没有括号**，混用会按 AND 优先错误结合：
```
篇名 AI OR 篇名 人工智能 AND 主题 法律 OR 主题 法规
→ 实际 = AI OR (人工智能 AND 法律) OR 法规   ← 错！4169
```
正确：`篇名 ("AI"+"人工智能") AND 主题 ("法律"+"法规")` → 4290 / 期刊 2365 ✅

### 坑 3：知网分面要点开才加载

11 个分组里**只有前 3 个默认有条目**，其余 8 个（作者/机构/年度/…）必须点 dt 标题才 AJAX 拉取。
脚本已自动展开（看到 `[facet] 展开: 作者` 就是它）。

### 坑 4：万方时间字段是「发表时间」

`发表时间:(2010-2024)` ✅ ／ `出版时间:(2010-2024)` ❌ 无效

### 坑 5：「机构」分面 ≠「学位授予单位」

知网的机构分面统计**作者单位**，不是学位授予单位。问"哪个学校授予的学位论文最多"时两者会有偏差
（详见 `作答记录_v13.md` 第 1.2 节）。
